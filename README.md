# Forest Mech — Scene 01 (playable build)

Static WebGPU build of a one-scene prototype: an offline **island salvage run**. Pilot a utility
mech, fell and mill timber, build a bridge or repair stations, and bank two of three power cores at
the home dock before a 12-minute storm, against two AI mechs. Each run is a **seeded island**
(`?seed=XXXXXX` replays one; `?seed=classic` is the hand-authored layout). Nothing is saved.
Rules and balance are provisional (v0.1). **WebGPU is required** (no WebGL fallback); browsers
without it show an explanation screen.

This repository holds only the built runtime files. Credits and licences: `THIRD_PARTY.md`.
